# Detector Fixture Benchmark

This directory contains minimal Codex JSONL traces that exercise the deterministic CodexTrace process rules.

It is not a real Codex collection tier and should not be used for outcome or prompt-intervention claims. Its role is narrower: verify that the offline diagnosis engine can recover each taxonomy label from trace-only process evidence when that evidence is explicitly present.

The real pilots remain the evidence for benchmark behavior, hidden-grader boundaries, and intervention waste metrics.
