# Verification Ablation Tier

This is an auxiliary ablation, not an ordinary Codex baseline.

The stored ordinary, weak-baseline, hard, process-stress, and verification-lift pilots all show saturated verification rates. This tier tests a narrower question: whether an explicit no-verification baseline and an evidence-gated intervention can control verification behavior in the harness.

Interpretation rules:

- Use this only as a harness-control ablation.
- Do not use it to claim ordinary Codex baseline verification is low.
- Do not use it to replace the main hard30 or full30 pilots.
- A positive verification-rate delta here supports the mechanism, not the original ordinary-baseline claim.
